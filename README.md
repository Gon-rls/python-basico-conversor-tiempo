Conversor de unidades de tiempo en Python con validación de datos y representación gráfica mediante Matplotlib.


# Conversor de Tiempo en Python

Proyecto sencillo desarrollado en Python para convertir una cantidad de segundos a diferentes unidades de tiempo: minutos, horas o días.

El programa está basado en una función que recibe como parámetros el número de segundos y la unidad de destino. Antes de realizar la conversión, se valida que el valor introducido sea numérico y no negativo. También se comprueba que la unidad seleccionada sea una de las opciones disponibles.

Dependiendo de la unidad elegida, se realiza la conversión utilizando las equivalencias correspondientes entre segundos, minutos, horas y días. El resultado se devuelve mostrando tanto el valor original como el valor convertido con dos decimales.

Además de realizar la conversión, el programa utiliza `Matplotlib` para generar un gráfico de barras que permite comparar visualmente la cantidad original de segundos con el resultado de la conversión.

Este ejercicio me ha servido para practicar la creación de funciones, validación y conversión de datos, estructuras condicionales y representación gráfica de resultados utilizando Python.
